# 🏡 Airbnb Homepage Clone

A responsive **Airbnb Homepage Clone** built with **React.js** as part of my internship assignment. The project focuses on recreating Airbnb's modern landing page using reusable React components and responsive design principles.

## 🚀 Live Demo

🔗 airbnb-smoky-psi.vercel.app

---

## 📌 Project Overview

This project is a front-end clone of the Airbnb homepage. The goal was to practice component-based architecture in React while creating a clean, responsive, and user-friendly interface.

---

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- Categories Section
- Property Listings
- "See All" Cards Section
- Interactive Menu Dropdown
- Fully Responsive Layout
- Reusable React Components
- Modern Airbnb-inspired UI

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/Mannsoni8/Airbnb
```

Move into the project directory

```bash
cd airbnb-homepage-clone
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
